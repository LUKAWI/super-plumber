星图节点 · 单节点静态与动效 demo

提案：整张拓扑 = 一片星空。未交互时每个节点是一颗按状态着色的星（halo 光晕 + 四向衍射星芒 + 微闪烁，北极星式）；hover 时星芒收拢、节点形态（状态环 / 标签 / 检查点条）浮现。零新依赖——SVG 滤镜 + CSS 动画，与现有 d3-force/缩放/拾取/无障碍管线完全同构。

配色全部取自 DESIGN.md 状态色正本；本页即提案自演示。

一颗星的解剖

四层结构，全部矢量：白色炽心（core，1.5px 级）→ 状态色 halo（radialGradient，半径≈3×星等）→ 四向衍射星芒（spikes，细菱形渐隐，北极星式）→ 微尘星点（天空语境层）。亮度（星等）映射节点层级 L0–L5，颜色映射状态。

映射规则（提案）

星体属性数据映射
颜色节点状态（七色正本，与现状一致）
星等 / halo 半径 / 芒长层级 L0 最亮 → L5 最暗（亮度 = 责任半径）
闪烁相位按节点 id 哈希取 phase——同一图每次加载星空不同，同星相位稳定
呼吸幅度running 幅度最大（0.82↔1.0 + 光点流保留），pending 最轻

rAF 成本：闪烁用 CSS animation（合成器走 opacity/transform），不做逐帧 JS；整片星空的辉光不逐帧重算。

样式变体画廊（六种 CSS/SVG 技法）

同一颗 RUNNING 星（#f0a73a）的六种画法。§2 的"菱形星芒"是现役默认；以下变体各有取舍——小尺寸可读性、动效成本、与 terminal 世界的契合度都列在表里。全部零依赖、纯 SVG/CSS。（2026-08-28 更新：V4 已拍板为星芒正本并落入 GraphCanvas，见 §5 表格标注。）

V1 弥散光斑
双层 radialGradient，无芒
V2 十字线芒
1px 线 + 高斯模糊副像，最"望远镜"
V3 像素十字
硬边矩形 + steps() 数字眨眼，最 terminal
V4 八向棱星
斜向短芒 + 红蓝错位色差（棱镜感）
V5 脉冲回环
回声环外扩——建议只给 running 专用
V6 幻环透镜
偏心细环=镜头鬼影，最"摄影味"

变体对比（图可读性优先）

变体小尺寸可读性动效成本terminal 契合建议用途
现役 菱形星芒好（芒即锚点）低好默认款
V1 弥散光斑弱（无锚线，缩小后成一团）最低一般微尘层/极小节点
V2 十字线芒好（1px 线锐利）低（一次 blur）好L0/L1 大星（精密感）
V3 像素十字好（硬边不糊）最低（无滤镜）最强缩小态 LOD / 挂屏远距
V4 八向棱星中（细节多，缩小易糊）中（色差双层）中✅ 已采纳（2026-08-28 拍板）——星芒正本，星态旁常显任务摘要
V5 脉冲回环好（运动即吸引）中（3 环持续动画）好仅 running 专用语义
V6 幻环透镜中（环与节点环混淆风险）低中备选，不建议默认

工具箱备注：以上用到的 CSS/SVG 手段——radialGradient/linearGradient、feGaussianBlur、steps() 动画、transform-box: fill-box、mix-blend-mode（V4 备选实现）、@property（渐变角动画，未用）。zoom 缩小时所有变体可统一切到 V3 像素十字做 LOD（硬边在低倍率下最不糊）。

hover 显形：星 → 节点形态

鼠标未接触时它是 RUNNING 状态的一颗星；悬停（或键盘 Tab 聚焦）时星芒收拢、halo 收暗，节点形态淡入——状态环、标签、检查点条，与现行节点视觉同构。点击行为不变（进节点详情）。

交互时序

220ms ease-out：星态不消失（保留 22% 亮度 + 0.82× 缩放作背景），节点形态在同位置浮现——"星星显形"而不是"星星消失"。移开后 220ms 回到星态。触屏长按 = hover 语义；键盘 Tab 聚焦即显形。

星空态下无文字（整片天空干净可挂屏）；一切文字只在显形态与选中详情里出现。

微缩星空语境（15 节点示意）

力导向坐标不变，只换皮肤：节点=星、边=座标星座线（白 0.45 → 0.35 视觉档）。星点大小按层级，颜色按状态，相位按 id。感受"整片天空"的密度与可读性。

缩放行为不变：zoom in 时星等半径随之放大（自然显形为节点），zoom out 时缩为纯星点——LOD 天然成立。整屏无文字，挂屏语义成立。

技术选型（调研结论）

方案结论理由
SVG + CSS 动画（本 demo）✅ 推荐与现有 d3-force/zoom/拖拽/无障碍/标签管线零冲突；halo=radialGradient、星芒=渐变菱形、闪烁=CSS animation（合成器路径）；零新依赖，符合 DESIGN.md 矢量世界与零依赖纪律
Threlte（three.js）+ <Stars> + Bloom❌ 已否决（2026-08-28 实测）两点实锤：① 上游发布链断裂——core@8.6.0 的产物不含 createRawEventDispatcher，而已发布的全部 extras（8.9–9.21）都在 import 它，版本无法对齐，需自行 fork/patch；② 原型实拍判定过重（用户裁决）：真 3D 景深+泛光对"图可读性"是负资产，且需整体替换拾取/缩放/标签/a11y 管线、打破零依赖纪律
tsParticles（@tsparticles/svelte）❌ 不采定位是装饰性粒子背景，无节点语义/拾取/状态绑定；为微尘层引入整库不值
Canvas 2D 底层微尘（可选增强）🟡 备选若几百节点后 SVG 微尘层性能吃紧，可加一层 canvas 画微尘+辉光（globalCompositeOperation: lighter）；节点本体仍留 SVG

实现落点（若批准）：GraphCanvas renderNodeLayer 的节点 g 内加 star-sky 组（halo/spikes/core），现有 node-circle/status-ring/label/cp 组整体包进 node-body 做 hover 交叉淡入；闪烁相位 = hash(node.id) % 3600ms；prefers-reduced-motion 关闪烁只留静态辉光。
