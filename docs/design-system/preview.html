五条设计原则

每条原则都对应评审中发现的具体问题，不是风格宣言。

一、色彩即状态，交互用明度

画布上唯一的彩色是 7 个节点状态色（评审确认其单源纪律做得好，保留）。选中、hover、focus、开关等一切交互态改用白色明度阶梯表达——废除"status-ready 蓝当复选框色"的语义劫持（App.svelte:643），从根上消灭"两套蓝"的打架（types.ts:177 边色 vs 状态色）。

二、画布即产品

顶栏从三排压到两排，左缘四个互不相识的浮层（MAPS / ADR 座 / zoom / versions）合并为一条统一工具轨，杜绝数学上必然的相互遮挡（视口 ≤768px 时 map-selector 与 AdrDock 重叠约 100px）。

三、每个状态都有出口

首屏黑屏（autoFit 与力导向赛跑）、切图黑屏、搜索无命中黑屏、空 diff 黑屏——四个"看起来像坏了"的时刻全部补上明示状态与恢复路径；Esc 与空白处点击成为全局退出手势。

四、mono 只为数据

等宽字体保留给 id、数字、命令、时间戳——它们是数据。UI 标签、按钮、标题回归 sans；SVG 内字号下限 10px（废除 8px/8.5px 硬编码），中文不再被 mono 拉散。

五、动效表达状态

130/220/450ms 三档 + 单一 ease-out 曲线；fit 不再是 setTimeout 魔数，而是挂接模拟收敛事件；prefers-reduced-motion 全量降级。

色彩

策略不变（Restrained：中性分层 + 单一彩色语义组），修的是三处硬伤：ink-faint 对比度、cancelled 状态色、交互色的语义劫持。所有色值按 WCAG 相对亮度公式核算，核算值标在注释。

动效

三档时长 + 单曲线，只表达状态变化。全部有 reduced-motion 降级（降为 opacity 或直切）。

token时长曲线用于
--t-fast130mscubic-bezier(0.22,1,0.36,1)hover、chip/tab 切换、颜色态
--t-med220ms同上面板滑入/滑出、flyout、开关
--t-slow450ms同上fit 取景、图切换过渡

节点入场 stagger（20ms）保留但仅首次布局；运行中节点的呼吸/光点动画改用 transform + 一次性 join（修复逐帧 O(n²) filter）。fit 时机挂接模拟 alpha 收敛，废除 setTimeout(2000)。

评审问题 → 提案映射

级别评审发现本提案的解
P0首屏/切图黑屏：autoFit(2000ms) 与 5.7s 力导向赛跑，取景失败无恢复路径fit 挂接模拟收敛；首帧低倍取景渐进逼近；切图/resize/透镜切换后强制 refit；黑屏期间显示"布局计算中"空态
P0画布键盘死路：SVG 节点无 tabindex/role，无 Esc，空白点击不取消选中节点 g 元素 tabindex+role+aria-label；全局 Esc 与空白点击退出；本提案所有示例带 focus 环
P0z 体系击穿：var(--z-tooltip,30) 实为 1000，移动端面板被盖，AdrDocument 打 1001 补丁五层 z 语义 + 工具轨（20）低于面板（100）
