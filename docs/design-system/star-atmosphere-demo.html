§2 hover = 声呐环（单次扩散）

§5 领域视图：虚线色框 → 彩色星云（候选）

左边是现状：context 以虚线圆环 + 填充呈现。右边是提案：换成按上下文着色的星云斑——云内 alpha 0.05-0.12（与背景预算同级，不构成光污染，且是语义色），虚线框退役，context 顶点以云心微尘点呈现。两个 context 之间的契约边仍是虚线（契约语言不变）。
