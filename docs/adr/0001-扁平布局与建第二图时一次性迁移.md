# 0001 — 扁平布局与建第二图时一次性迁移

多图布局为 .graph/<图名>/ 扁平一级目录（每图一个目录，图内=完整既有布局）；旧仓库零迁移兼容（.graph/graph.yaml 原地识别为 default），创建第二张图时在工作区级锁内一次性 renameSync 7 项进 .graph/default/，此后单一布局路径。

**Status：** accepted

**Context：** 多图管理需要新存储布局。备选：graphs/ 嵌套层+永不迁移（永久双布局代码路径）；原地平铺+保留名黑名单（易撞系统目录）。

**Considered Options：** graphs/ 嵌套层→旧 default 原地与子目录长期共存，双解析路径永久化; 原地平铺不加层→图名需黑名单且区分系统目录靠启发式; 扁平+一次性迁移←选中（单一布局+迁移一次性成本）

**Why：** 迁移只发生一次（第二图诞生时刻，用户主动、非执行中），换掉永久双路径复杂度；每图独立锁/索引/事件/快照随目录隔离自动成立。

**Consequences：** 迁移窗口需工作区级锁兜底（__ws_migrate__）；旧布局只读 fallback 保留；图名受 ^[a-z][a-z0-9-]{0,38}$ 约束
