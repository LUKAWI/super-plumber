# 0018 — 工作类按可信交付计划定档（修订 DEC-2）

顺序定档：① 关键未知是否阻止形成可信交付计划？是则 program；否则② 一个会话内能完成并验收吗？是则 quick，其余 standard。可信计划要求目标、范围、验收明确，主要任务与关键依赖可列出，剩余未知可在具体节点内解决。关键未知的答案会决定交付范围、主要方案或关键依赖，使当前完整交付计划无法可信成立。跨会话、跨图、跨仓库和并行人数不单独触发 program。quick 保持单节点图、entry/exit 各一句话、仅 validate、跳过 doctor/serve 人审、approve --status self 自签及 claim→report→passed（checkpoint 可选）；standard 保持完整设计审核、按依赖执行与三层验收。program 画已知骨架，在 fog.description 写未知及影响的决定，graduation 写可验证证据，审核当前研究计划、毕业条件与已明确部分，逐票研究并回写决策。standard 仅在关键未知使主要计划失效时提出转 program；program 仅在关键未知解决、可信计划成立且经增量人审后转 standard，研究票全部 passed 或 fog 清空不单独触发转档。需求描述模糊先澄清；仅对会话容量存疑时按 standard。保留用户指定档位、变更凭据及零新增机器门禁规则。
