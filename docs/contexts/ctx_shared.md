# 共享工件上下文（ctx_shared）

跨工具复用的机械共享件：Operations 手册唯一正本、斜杠命令文案正本、构建期同步脚本。不承载任何工具特有格式，也不做任何工具的流程裁决。

## 术语表

- **手册**: 唯一的命令语法真相源：三访问层（MCP 工具/CLI graph/sp-*.mjs 脚本）语法、状态机全表、错误处理、solo 机械裁决清单；按需 Read/注入，永不整段内嵌进提示词或 skill 正文
- **机械共享件**: 正文只维护一份、构建期同步拷贝进三个集成包的工件（手册、斜杠命令文案、sp-*.mjs）；与手工分别写的角色文本相对；改一处其余靠脚本对齐并有一致性校验
- **三归类**: 对现有 skill 逐段贴标签的评审方法：编排语义留 skill／角色专业协议归对应 agent 提示词／操作语法进手册；换归属≠删除，动刀前清单须用户批准
- **派单模板**: 主线程给 subagent 派活用的标准任务提示词骨架：任务目标+显式文件边界（防越界）+首行固定 Read 手册对应章节；信息优先级为 任务派单>角色提示词/手册>skill 正文
- **正本**: 唯一维护源文件，散布在各集成包中的同名内容一律是其拷贝而非第二真相源
- **同步脚本**: 将正本拷贝进三集成包并断言一致性的 sync-integrations 脚本；漂移即非零退出
