# GraphCanvas 中键平移交互说明

## 交互约定

- 在画布空白处或节点上按住鼠标中键（`button=1`）并移动，视图连续平移。
- 中键拖动开始时画布捕获该 pointer；`pointerup`、`pointercancel`、`pointerleave`、`lostpointercapture` 或组件卸载都会结束本次平移并释放 capture。
- 左键继续用于节点选择与节点拖动；左键拖动画布不平移。
- 滚轮继续缩放，双击继续重置视图，右键继续交给浏览器/应用菜单处理。
- 触控仍由 d3-zoom 的 touch 手势处理；中键处理器只响应非 touch 的 `button=1`。
